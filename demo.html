All-optical image denoising using a diffractive visual processor

Işıl, Çağatay · Gan, Tianyi · Ardic, Fazil Onuralp · Mentesoglu, Koray · Ozcan, Aydogan

Abstract

Image denoising is one of the essential inverse problems. This work presents an all-optical visual processor that removes noise and artifacts from input images with a diffractive optical network.
